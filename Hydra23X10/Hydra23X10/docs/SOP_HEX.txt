Hydra23X10 compile output (SOP)

After a successful EngineHR Hydra build, copy .bin / .hex / .dfu to:

  C:\Repetrel\bin\firmware\Hydra_CanBoot

Debug_EngineHR_Hydra and Release_EngineHR_Hydra post-build do this automatically.

Publish
-------
Copy .bin and .dfu into PublishFilePath only when the user tells Grok to PUBLISH.
Compile does not copy them. Push does not copy them. The Repetrel Hydra_CanBoot
copy above stays a post-build step. It is not the UploadFiles publish.
Canonical text: ~/.grok/rules/sop.md

RevisionHistory.h defines:

  #define PublishFilePath "C:\\Users\\karl6\\Documents\\UploadFiles\\"

On PUBLISH, copy Hydra23X10.bin (and the .dfu when the build produced one) to:

  C:\Users\karl6\Documents\UploadFiles\firmware\HYREL\Hydra23X10_rev{revision}.Bin
  C:\Users\karl6\Documents\UploadFiles\firmware\HYREL\Hydra23X10_rev{revision}.dfu

Examples already in that folder:

  Hydra23X10_rev26.008A.Bin
  Hydra23X10_rev4.256k.Bin

Use the revision string this product already publishes (HB revision or MajorStep).
